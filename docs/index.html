首次安装，请留意系统提示

当前版本使用本地签名，尚无 Apple Developer ID 证书及苹果公证。

  1. 下载并拖入“应用程序”

    打开 DMG，将“π 提醒.app”拖入 Applications。也可下载 ZIP 后解压安装。

  2. 按 macOS 提示允许打开

    确认来源可信后，先尝试打开一次，再到“系统设置 → 隐私与安全性”选择“仍要打开”。查看 Apple 官方指引 ↗

  3. 跟随引导，连接自己的日历

    按需允许日历、麦克风和语音识别权限。飞书首次配置后扫码连接；模型接口可稍后设置。

无需关闭 Gatekeeper 或 SIP。若系统提示恶意软件、会损坏电脑或签名损坏，请停止安装并核实来源；企业电脑可能需要管理员批准。

你可能还想知道

以后怎么更新？

在“设置 → 软件更新”中手动检查，或开启每天自动检查与后台下载。更新包会验证签名，保留本机记录与设置。没有更新入口的旧版需先手动安装新版一次。尚无苹果开发者签名与公证，因此不能保证系统永不再次提示信任或权限。

一定要配置大模型 API 吗？

不需要。可以直接使用本地识别；需要模型辅助时，再配置自己的兼容接口、模型和 API Key。模型服务的费用与可用性由你的服务商决定。

飞书能直接扫码使用吗？

官方飞书组件已内置。如果新电脑没有飞书应用配置，请先在“设置 → 日历连接”中打开首次配置向导，再扫码授权并选择日历。所在企业的应用和权限政策可能需要管理员批准。

缴费期限是软件自动确定的吗？

不是。对适用的受理费通知，软件可依据 PDF 内嵌生成日期，从次日起按默认七个自然日暂估；生成日期不等于送达日期，也不会自动处理节假日顺延。请根据通知书与实际收件情况修改基准日、天数和到期日。依据缺失或不适用时需手动补充。

只说“明天联系客户”，可以吗？

可以。软件保留已识别的日期，并给出可修改的建议时间，例如未说几点时建议上午九点。录音时也能继续打字，结束后合并内容，再由你核对并添加到日历。

文书里的日期已经过去了，怎么办？

软件会显著提示旧日期，不会擅自改成未来时间。核实后，可以再次确认并按原日期添加；缺少日期或期限依据的事项仍需先补齐。

标记完成或清空输入，会取消提醒吗？

不会。标记完成只记录事项已办完；清空界面只清除当前输入与展示。苹果、飞书中已有的日程和通知仍然保留。日历接收成功也不等于通知必然触达，请同时留意设备权限、勿扰模式和日历客户端设置。

怎样支持 π 提醒继续完善？

应用“设置”内提供赞助入口，可选择微信或支付宝。赞助完全自愿，不影响现有功能，也不等同于购买软件授权或法律服务。

日历会展示所有外部日程吗？

不会。主界面只展示本软件管理的事项，不做苹果或飞书日历的全量同步。文书识别完成也不代表已经入历，请以对应目标的接收状态为准。
