小模型装在本机，
随手记就地整理。

“本地智能”内置轻量小模型，配合中文日期规则，帮你从随手记中整理事项、时间与明确地点。无需另行部署模型，无需 API Key，本地识别过程不上传输入内容。

  • 文字 PDF 直接读取，扫描件可在本机 OCR
  • 云端 OCR 与云端文字整理按需选用
  • 账户凭据不放进文书或安装包
  • 日期、金额和主体，始终留给你核对
  • 设置内可查看完整隐私与使用说明
小模型用于随手记整理，不代替文书 OCR，也不判断法律期限。复杂扫描件可选 PaddleOCR 或 MinerU；云端文字整理另行可选，发送前由你确认。添加日历会连接所选日历服务。

首次安装，请留意系统提示

当前版本使用本地签名，尚无 Apple Developer ID 证书及苹果公证。

  1. 下载并拖入“应用程序”

    点击下载按钮即可下载安装包。打开 DMG，将“π助手.app”拖入 Applications。其他格式可在页尾“版本与下载”中获取。

  2. 按 macOS 提示允许打开

    确认来源可信后，先尝试打开一次，再到“系统设置 → 隐私与安全性”选择“仍要打开”。查看 Apple 官方指引 ↗

  3. 跟随引导，连接自己的日历

    按需允许日历、麦克风和语音识别权限。飞书首次配置后扫码连接；本地识别可直接使用，云端服务按需配置。

无需关闭 Gatekeeper 或 SIP。若系统提示恶意软件、会损坏电脑或签名损坏，请停止安装并核实来源；企业电脑可能需要管理员批准。

你可能还想知道

以后怎么更新？

在“设置 → 软件更新”中手动检查，或开启每天自动检查与后台下载。更新包会验证签名，保留本机记录与设置。没有更新入口或曾关闭更新的内测版，请先退出应用，下载后替换原安装位置一次，保留本机数据，之后即可检查更新。尚无苹果开发者签名与公证，因此不能保证系统永不再次提示信任或权限。

一份文书里有多项财产，怎么核对？

在清单中按主体、到期日或异常筛选，选中一项查看详情，再勾选需要添加的事项。财产尾号、子账户、金额与日期分别呈现；缺失或冲突会提示核对，不自动猜补。拆分后的日程备注只保留对应财产内容。

一定要配置大模型 API 吗？

不需要。软件已封装本地小模型和运行组件，“本地智能”可以直接使用，无需自行安装模型或填写 API Key。复杂文字可按需选择云端整理；扫描件的云端 OCR 可选 PaddleOCR 或 MinerU，彼此独立，费用与可用性以服务商说明为准。

本地小模型能做什么？

它面向随手记的文字整理，辅助提取原句中明确的地点，并对不确定的事项类型给出核对提示；时间由本地日期规则解析。它不是通用聊天模型，也不会替你推算法定期限。长句、多地点或含糊表达仍需手动核对；识别结果不会未经确认就写入日历。

飞书能直接扫码使用吗？

官方飞书组件已内置。如果新电脑没有飞书应用配置，请先在“设置 → 日历连接”中打开首次配置向导，再扫码授权并选择日历。所在企业的应用和权限政策可能需要管理员批准。

缴费期限是软件自动确定的吗？

不是。对适用的受理费通知，软件可依据 PDF 内嵌生成日期，从次日起按默认七个自然日暂估；生成日期不等于送达日期，也不会自动处理节假日顺延。请根据通知书与实际收件情况修改基准日、天数和到期日。依据缺失或不适用时需手动补充。

只说“明天联系客户”，可以吗？

可以。软件保留已识别的日期，并给出可修改的建议时间，例如未说几点时建议上午九点。录音时也能继续打字，结束后合并内容，再由你核对并添加到日历。

文书里的日期已经过去了，怎么办？

软件会显著提示旧日期，不会擅自改成未来时间。核实后，可以再次确认并按原日期添加；缺少日期或期限依据的事项仍需先补齐。

删除记录或清空输入，会取消提醒吗？

请留意确认框：普通日历事项可确认后同步删除，并核对外部结果；周期日程、多人会议、权限不足或状态不明的事项会限制操作。仅隐藏本机记录不会删除外部日历。同步删除后恢复为待确认，需核对后重新添加；彻底删除记录后不可恢复。清空输入不会取消已有日程。日历接收成功也不等于通知必然触达，请同时留意设备权限、勿扰模式和日历客户端设置。

怎样支持 π助手继续完善？

应用“设置”内提供赞助入口，可选择微信或支付宝。赞助完全自愿，不影响现有功能，也不等同于购买软件授权或法律服务。

日历会展示所有外部日程吗？

可以集中查看已连接并启用的苹果、飞书日历，具体范围由来源与读取设置决定，不代表全部历史日程。文书识别完成也不代表已经入历，请以对应目标的接收状态为准。
