# π 提醒 · 安装与更新

这里仅发布 macOS 安装包、更新源及使用说明，不包含源代码、用户文书或账户凭据。

[下载最新版本](https://github.com/susssed/pi-reminder-releases/releases/latest)

## 适用电脑
Apple 芯片 Mac，macOS 14 或更新版本。尚不支持 Intel Mac、Windows 和手机。

## 安装
打开 DMG，将“π 提醒.app”拖入“应用程序”。本软件没有 Apple Developer ID 证书及公证；确认下载来源后，按 [Apple 官方指引](https://support.apple.com/zh-cn/102445) 在“系统设置 → 隐私与安全性”中选择“仍要打开”。不要关闭 Gatekeeper 或 SIP。

## 更新
0.7.0 起，在“设置 → 软件更新”中检查新版本、设置每天检查与后台下载。更新包用 Ed25519 签名校验。旧版没有该入口，需先手动安装新版本一次。保持相同签名身份，但不保证系统绝不再次要求安全确认或日历权限。

## 首次使用
苹果日历、麦克风及语音识别权限按需要由使用者授权。飞书官方组件已内置，新电脑需完成自己的飞书应用配置及扫码登录；不共享提供者凭据。模型辅助可选，需要使用者配置自己的 API。

完整操作与限制见每个版本的安装说明。本机记录与设置保存在用户目录中，不放入安装包。
